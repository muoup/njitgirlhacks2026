# Watering and moisture trends

Use recent trends, timestamps, species, and explicit user observations together.
Consult sensor-quality before interpreting measurements. A sensor percentage is
provisional unless calibration and healthy ranges are supplied; do not invent a
universal watering threshold or exact watering schedule from one number.

Explain which plant and time window informed a recommendation. Suggest checking
the soil and drainage when evidence is incomplete. Ask about indoor/outdoor placement,
potting medium, weather, or recent watering when relevant. Avoid prescribing extra
water solely because a sensor stopped reporting. Never claim suggested care happened.
